Debt Classification Lab

You are a credit-risk analyst at a consumer finance company. Sort 120 loans into debt groups by days past due, work out the provisions, measure bad debt and see how loans move between groups. Write SQL, Python and Excel formulas right here and check each result.

SQL (SQLite) Python (core language) Excel formulas

The brief

Lotus Consumer Finance (a made-up company) lends to individuals: personal loans, motorbike loans, credit cards and appliance installments. At every month-end the risk team puts each loan into one of five debt groups by days past due (dpd, the number of days the oldest unpaid amount is overdue) and sets aside a provision for each group. You have the loan book at 30 Sep 2026, the same book one month earlier in the column dpd_prev (31 Aug 2026), and the rules table. All amounts are in VND.

The rules are a simplified version of Circular 11/2021/TT-NHNN (as amended by Circular 31/2024/TT-NHNN) on asset classification and provisioning in Vietnam. Groups 3, 4 and 5 are bad debt (non-performing loans, NPL). Provision for a loan = outstanding × the rate of its group. Collateral, restructured loans and the qualitative criteria are left out, so this is a teaching model and not compliance advice.

SQL

The rules live in a table, so classification is a join on a range. Change a threshold in rules and every query follows. Window functions handle the customer-level rule without any loop.

Python

A small function holds the rule and loops apply it. It is the easiest place to add logic that does not fit a table, such as qualitative overrides or restructuring flags.

Excel

Risk and finance teams can see every step: the group of each loan, the provision, the totals. The helper columns make audit easy, but the layout is manual, so a sixth group means new rows and new formulas.

The data is generated for this lab and is not a real portfolio. The SQL runs on SQLite, the Python on a small built-in interpreter (loops, dicts, lists, comprehensions, functions, f-strings, math and collections), and the Excel formulas on a small built-in engine. Rules and thresholds follow the public text of the regulation, simplified for teaching: Circular 11/2021/TT-NHNN (English), specific provision rates by group, the five debt groups explained, general provisions (not used here).
