SQL

Shortest when the data already sits in tables. You describe the result and the engine picks the plan. Window functions cover anything that depends on neighbouring rows.

Python

You write the steps: loop, test, update a variable. It is the most flexible, and the same logic scales to any data you can load. With pandas the same four tasks shrink to a few lines each.

Excel

Best when people must see and audit every number or change inputs and watch results move. You lay out the groups yourself, so new months or products mean new rows or columns.

Download the Excel workbook with the data and one reference solution per task.

The data is generated for this lab. The SQL runs on SQLite, the Python runs on a small built-in interpreter (loops, dicts, lists, comprehensions, f-strings, math and collections), and the Excel formulas run on a small built-in engine. All three give the same results on these 90 orders.
